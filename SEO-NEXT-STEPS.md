# Silm Academy SEO — next steps

Canonical site: https://thahirhassa132010.github.io/silmacademysite/

## After publishing
1. In Google Search Console, submit `sitemap.xml`.
2. Inspect the canonical homepage URL above and use **Request Indexing** after the updated deployment is live.
3. Keep the academy name, address and course information consistent across the website and legitimate public profiles.
4. Add real, useful course pages or sections as the academy grows (for example Hifz, Arabic and Islamic Studies), with unique content rather than duplicate keyword pages.
5. Add the official social/profile URLs to the Organization structured data only when those profiles actually exist.

## Important
The canonical URL is intentionally the GitHub Pages project URL (`/silmacademysite/`), not the account root. This prevents Google from being told that a different URL is the representative version of the page.

Do not create many pages solely to target spelling/location variations. Focus on useful content for real visitors.
