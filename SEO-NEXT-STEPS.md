# Silm Academy SEO next steps

This version focuses on the exact brand phrase “Silm Academy” and the location phrase “Silm Academy Mangalore” without keyword stuffing.

After publishing to GitHub Pages:
1. Verify these URLs open:
   - /silmacademysite/
   - /silmacademysite/about.html
   - /silmacademysite/courses.html
   - /silmacademysite/admissions.html
   - /silmacademysite/contact.html
   - /silmacademysite/sitemap.xml
2. In Google Search Console, keep the sitemap `sitemap.xml` submitted.
3. Use URL Inspection to request indexing for the four new pages.
4. Monitor Performance > Queries for “Silm Academy” and local variations.

Google can choose a different canonical or ranking even when a canonical is specified, so rankings are not guaranteed.
